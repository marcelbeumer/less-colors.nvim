                                                                  *less-colors*

Removes colors from syntax highlighting. Some languages are beautiful as they
are without colors (like Go).

Because simply turning off vim and treesitter syntax highlighting sometimes
caused issues with other plugins this plugin maps highlight groups back to
"Normal". This way all bells and whistles can stay enabled including
non-syntax colors of a colorscheme.

Currently works on default colorscheme. Needs more mapping to de-colorize
colorschemes that use more highlight groups, which is most modern colorscheme
plugins.

This module needs a setup with `require('less-colors').setup({})` where `{}`
can be your config table in case you want to override defaults.

See |less-colors-config| for the config table structure and defaults.

------------------------------------------------------------------------------
setup({config})                                             *less-colors-setup*

Module setup

Parameters ~
{config} `(table|nil)` Module config table. See |less-colors-config|.

Usage ~
>lua
  require('less-colors').setup() -- use default config
  -- OR
  require('less-colors').setup({}) -- replace {} with your config table
<
------------------------------------------------------------------------------
Config                                                     *less-colors-config*

Defaults ~
>lua
  {
    enabled = true, -- general enable/disable
    enable_command = "LessColors",
    disable_command = "MoreColors",
    toggle_command = "LessColorsToggle",
    commands = true, -- add commands during setup
    autocmd = false, -- automatically re-apply on colorscheme change
  }
<

------------------------------------------------------------------------------
Commands                                                 *less-colors-commands*

:LessColors                                                       *:LessColors*
    Enable (remove syntax highlighting colors).

:MoreColors                                                       *:MoreColors*
    Disable (restore syntax highlighting colors).

:LessColorsToggle                                           *:LessColorsToggle*
    Toggle less-colors on/off.

Note: Commands are only created if `commands = true` in config.
